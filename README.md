# 🤖 Python AI Terminal Assistant

An interactive Command-Line Interface (CLI) application built with Python to interact with Large Language Models (LLMs) via REST APIs.

## 🚀 Features
- **Interactive Prompting:** Allows dynamic queries directly from the terminal.
- **REST API Integration:** Handles HTTP requests and JSON responses securely using Python's `requests` library.
- **Security-Minded Architecture:** Designed to handle sensitive credentials safely via environment variables.

## 🛠️ Prerequisites
- Python 3.10+
- `requests` library
